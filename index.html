About

About EyeTrackIn

EyeTrackIn is a desktop software project focused on simplifying the acquisition, organization, visualization, and analysis of eye-tracking data.

It is built with research in mind: the goal is to transform raw gaze data into useful information, within a single, coherent environment.

The project is intended for researchers, professionals, developers, and anyone interested in visual attention and human-computer interaction.

  • Professionals
  • Developers
  • Curious minds
